# Web Development Activity — Website README

This package documents three standalone HTML web pages supplied for review.

## Included websites

1. **Personal Portfolio** — `personal information website.html`
   - Personal introduction, education, technical skills, hobbies, projects, achievements, resume section, and contact form.
   - Dark theme, responsive navigation, animated profile artwork, scroll-reveal effects, and active navigation highlighting.

2. **Online Learning Platform (LearnHub)** — `Online Learning Platform Interface.html`
   - Course catalogue, category filters, course search, course cards, instructor profile panel, learning-progress bars, and enrollment/continue-learning demo actions.
   - Responsive card layout and toast-style feedback for demo actions.

3. **Student Dashboard** — `Student Dashboard.html`
   - Student profile details, CGPA and attendance summary cards, semester results, subject details, attendance progress bars, examination schedule, and announcements.
   - Sidebar anchor navigation, tables, cards, and a mobile layout.

## Technology

- HTML5 for page structure and semantic content.
- CSS3 for colors, typography, layouts, cards, responsive media queries, and animation.
- Vanilla JavaScript for interactive behaviors on the portfolio and learning platform. The dashboard is primarily static HTML/CSS.
- No build step or package installation is required.

## How to run

1. Extract the ZIP package.
2. Open any of the three `.html` files in a current browser (Chrome, Edge, Firefox, or Safari).
3. To edit a page, open its HTML file in a code editor such as Visual Studio Code or Notepad, make changes, and save.
4. Refresh the browser to view the changes.

## Screenshots

The `screenshots/` folder contains preview screenshots (first screen), full-page screenshots, and a combined overview image. The screenshots were rendered from the supplied HTML files at a desktop viewport of 1440 × 1000 pixels.

## Important notes / limitations

- The websites are front-end demonstrations; they do not use a backend or database.
- Portfolio content contains example/placeholder details. Replace the email, education history, achievements, and other sample content with accurate information. The resume button expects a `resume.pdf` file in the same folder.
- The portfolio contact form opens a pre-addressed email draft; it does not send or store messages itself. Replace `yourname@example.com` in the HTML with the correct email address.
- LearnHub courses, instructors, ratings, student counts, and progress values are illustrative. Sign-up/enrollment interactions are demo-only and do not create real accounts or save progress.
- Student Dashboard marks, CGPA, attendance, student ID, subjects, and exam schedules are sample data. It is not connected to a university system.
- Review all placeholder and sample data before academic submission or public hosting.
